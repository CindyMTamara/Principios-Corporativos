# Misión Principios · Sopa de letras

Juego web educativo basado en principios corporativos. Funciona con HTML, CSS y JavaScript puro.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `style.css` y `script.js` a la raíz.
3. Ve a **Settings > Pages**.
4. Selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**.
5. Guarda.

## Funciones
- Tres niveles de dificultad.
- Palabras en ocho direcciones.
- Selección por clic o gesto táctil.
- Tiempo, puntos, pistas y progreso.
- Explicación educativa al encontrar cada concepto.
- Diseño responsive para ordenador, tableta y móvil.
